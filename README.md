# Dir_NN — navigation / azimuth networks + visualizations

This repo contains a few small PyTorch models for learning navigation signals from satellite map crops:

- **Azimuth prediction**: given a map crop + a **current** tile + a **target** tile, predict the direction (azimuth) from current to target as `(cos θ, sin θ)`.
- **Trajectory azimuth**: given **previous tiles** + current tile + target tile, predict the same direction.
- **CUR localization heatmap**: given a map crop + the **CUR** tile, predict a **probability heatmap** over the map crop of where CUR is located.

It also includes multiple visualization scripts (OpenCV overlays, interactive viewers).

---

## Requirements

The code assumes:

- Python 3.10+ (3.11 is also fine)
- PyTorch + torchvision
- Common libs: `numpy`, `pandas`, `Pillow`, `opencv-python`, `tqdm`

If you don’t have them yet, you can install quickly (example):

```bash
pip install torch torchvision numpy pandas pillow opencv-python tqdm
```

> Note: If you want CUDA, install the correct PyTorch build for your system.

## Repo structure (high level)

- `create_dataset.py`: dataset generator + `NavigationDataset` used by azimuth/attention/localization.
- `network_training.py`: baseline azimuth model (map + cur + tar → `(cos,sin)`).
- `network_training_attention.py`: azimuth model with **attention pooling** on the map.
- `network_training_trajectory.py`: trajectory model (prev tiles + cur + tar → `(cos,sin)`).
- `cur_localization_net.py`: `CurLocalizationNet` (map + cur → **logits heatmap**).
- `cur_localization_training.py`: train script for `CurLocalizationNet`.

Visualizations:

- `network_visualization.py`: visualize azimuth prediction (baseline model) on a sample.
- `network_visualization_rgb.py`: same, for `dataset_rgb`.
- `visualize_manual_interest_dataset.py`: interactive viewer for manual-interest trajectory CSV (prev tiles + cur + tar).
- `visualize_attention_manual_interest_traj.py`: interactive viewer that runs **AzimuthNetAttention** on a manual-interest trajectory CSV and overlays prediction.
- `visualize_cur_localization_heatmap.py`: render CUR-localization heatmap overlay image (JET heatmap + CUR box).

Data:

- `dataset/annotations.csv`: main annotations for azimuth models (with `split` column).
- `dataset/annotations_manual_interest_traj.csv`: manual-interest trajectory annotations (crop + prev tiles + cur + tar).
- `dataset/satellite_maps/`: source maps for `annotations.csv` (the dataset loader resolves `.tif/.jpg/.png/...`).
- `big_sample5_17.tif`: large source image used by the manual-interest trajectory CSVs.

## Dataset formats

### 1) `dataset/annotations.csv` (for `NavigationDataset`)

Generated by `create_dataset.py`. Each row describes a `map_id` and a square crop (default `1000x1000`) within that map.

Important columns:

- `map_id`: base filename of the source map (without extension)
- `map_crop_x`, `map_crop_y`: top-left of crop in pixels
- `cur_tile_x`, `cur_tile_y`: CUR center in pixels **inside the crop**
- `tar_tile_x`, `tar_tile_y`: TAR center in pixels **inside the crop**
- `vector_dx`, `vector_dy`: TAR - CUR (pixels)
- `split`: `train` / `val` / `test`

The `NavigationDataset` returns:

- `sat_img`: crop tensor `(3, 1000, 1000)` by default
- `cur_tile`, `tar_tile`: tile tensors `(3, 200, 200)` by default
- `labels` dict:
  - `cur_xy`: CUR center normalized to `[0,1]` (x/map_size, y/map_size)
  - `tar_xy`: TAR center normalized to `[0,1]`
  - `vector`: `(dx,dy)`

### 2) `dataset/annotations_manual_interest_traj.csv`

Trajectory-style CSV produced by `create_manual_interest_trajectory.py`. It uses a **big** source image (default `big_sample5_17.tif`) and defines a crop (default `2000x2000`) inside it.

Important columns:

- `map_crop_x`, `map_crop_y`: top-left of crop in the big image
- `cur_tile_x`, `cur_tile_y`, `tar_tile_x`, `tar_tile_y`: centers inside the crop
- `prev1_tile_x/y` … `prev4_tile_x/y`: optional previous centers
- `vector_dx`, `vector_dy`: TAR - CUR (pixels)

## Training

### A) Train AzimuthNetAttention (map + cur + tar → azimuth)

```bash
python network_training_attention.py \
  --annotations dataset/annotations.csv \
  --map-dir dataset/satellite_maps \
  --batch-size 8 \
  --epochs 20 \
  --lr 1e-3 \
  --save-path azimuth_net_attention.pt
```

### B) Train TrajectoryNet (prev tiles + cur + tar → azimuth)

This uses the big source image directly (default `big_sample5_17.tif`) and the trajectory CSV:

```bash
python network_training_trajectory.py \
  --annotations dataset/annotations_manual_interest_traj.csv \
  --map-image big_sample5_17.tif \
  --batch-size 8 \
  --epochs 20 \
  --lr 1e-3 \
  --save-path azimuth_net_trajectory.pt
```

### C) Train CUR localization heatmap (map + cur → heatmap)

This trains `CurLocalizationNet` to put high probability mass near the ground-truth `cur_xy`.

```bash
python cur_localization_training.py \
  --annotations dataset/annotations.csv \
  --map-dir dataset/satellite_maps \
  --batch-size 8 \
  --epochs 20 \
  --lr 1e-3 \
  --save-path cur_localization_net.pt
```

**Notes about validation loss**

- It is normal to see **train loss continue to drop** while **val loss stops improving** (overfitting).
- The script saves the **best checkpoint by val loss** to `--save-path`. For visualizations, use that file.

## Visualizations

### 1) Visualize baseline azimuth prediction (single sample)

```bash
python network_visualization.py \
  --annotations dataset/annotations.csv \
  --map-dir dataset/satellite_maps \
  --model-path azimuth_net.pt \
  --index 0 \
  --save-path viz_example.png
```

The saved image shows:

- green box: CUR tile
- yellow box: TAR tile
- red arrow: model-predicted direction from CUR

### 2) Interactive viewer: manual-interest trajectory CSV (no model)

```bash
python visualize_manual_interest_dataset.py \
  --input-image big_sample5_17.tif \
  --annotations dataset/annotations_manual_interest_traj.csv
```

Controls:

- `R`: next sample
- `E`: previous sample
- `Q` / `Esc`: quit

### 3) Interactive viewer: attention azimuth model on manual-interest trajectory CSV

Overlays the model-predicted direction from CUR:

```bash
python visualize_attention_manual_interest_traj.py \
  --input-image big_sample5_17.tif \
  --annotations dataset/annotations_manual_interest_traj.csv \
  --model-path azimuth_net_attention.pt
```

Overlay meaning:

- `P1..P4`: previous tiles (colored boxes)
- `CUR`: green box
- `TAR`: yellow box
- red arrow: geometric CUR→TAR
- blue arrow: model prediction

### 4) Visualize CUR localization heatmap (save overlay PNG)

```bash
python visualize_cur_localization_heatmap.py \
  --annotations dataset/annotations.csv \
  --map-dir dataset/satellite_maps \
  --model-path cur_localization_net.pt \
  --index 0 \
  --save-path viz_cur_heatmap.png
```

The output image:

- satellite crop in the background
- JET heatmap overlay of predicted CUR distribution
- green rectangle: ground-truth CUR tile

## Troubleshooting

### “Test split is empty”

Your CSV likely has no rows with `split == "test"`. Check the `split` column or regenerate the dataset.

### “Model weights not found”

The visualization scripts can run without weights (random model), but results will look random.
Train first and pass the correct `--model-path`.

### OpenCV window doesn’t show / crashes

Use the “save image” visualizers (`network_visualization.py`, `visualize_cur_localization_heatmap.py`) instead of interactive ones,
or ensure your environment supports GUI windows.

## Quick start (typical workflow)

1. Train attention azimuth model:

```bash
python network_training_attention.py --annotations dataset/annotations.csv --map-dir dataset/satellite_maps --save-path azimuth_net_attention.pt
```

2. Visualize on manual-interest trajectory CSV:

```bash
python visualize_attention_manual_interest_traj.py --input-image big_sample5_17.tif --annotations dataset/annotations_manual_interest_traj.csv --model-path azimuth_net_attention.pt
```

3. Train CUR-localization model and visualize heatmap:

```bash
python cur_localization_training.py --annotations dataset/annotations.csv --map-dir dataset/satellite_maps --save-path cur_localization_net.pt
python visualize_cur_localization_heatmap.py --annotations dataset/annotations.csv --map-dir dataset/satellite_maps --model-path cur_localization_net.pt --index 0 --save-path viz_cur_heatmap.png
```
